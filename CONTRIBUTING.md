# Contributing to Royal Murshad AIOS

## Ground Rules
1. **Respect Engine:** No shame. No judgment. No humiliation.
2. **Preserve existing work.** Do not refactor working modules without an approved issue.
3. **Honesty about status.** Any capability claim in docs must be backed by working code.
4. **No secrets in PRs.** Ever.

## Pull Requests
- Clear summary of what changed and why
- Tests for new logic
- Updated docs if behavior changed
