# Architecture

One integrated system, not disconnected products.

Royal Intelligence Core - reasoning, planning, model runtime, context, permission checks.
Royal Agent System - defined roles, delegation, shared context, controlled access.
Royal Computer Operator - Understand, Plan, Authorize, Execute, Verify, Report.
Royal Memory System - structured storage, retrieval, semantic search, access controls.
Royal Application Ecosystem - unified shell, sidebar, navbar, modular views.
Royal Automation Engine - scheduling, events, multi-step workflows, retries, history.
Royal Data System - records, memory indexes, workflow history, audit, backup.
Royal Security Layer - identity, permissions, encryption, audit logs, isolation.

Status: intended architecture. Implementation tracked in README.
